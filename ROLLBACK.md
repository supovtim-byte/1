- Тег содержит весь сайт, включая прежние файлы детской страницы, общие стили и скрипты. Он не передвигается при новых публикациях.

Чтобы отменить именно аудит, сохранив историю и последующие независимые изменения:

1. Выполните `git fetch origin --tags`, перейдите на `main` и обновите её через `git pull --ff-only origin main`.
2. Найдите коммит слияния: `git log --first-parent --merges --oneline --grep='Audit children page adaptive layout and interactions'`.
3. Выполните `git revert -m 1 SHA`, подставив найденный SHA. При наличии более поздних правок разрешите конфликты с их учётом.
4. Выполните `npm run check` и отправьте коммит в `main`; существующий workflow GitHub Pages опубликует откат. Если отменяется весь аудит, добавленная им команда браузерной проверки также удалится — для отката она не требуется.

Для просмотра резервной версии без изменения основной ветки: `git worktree add ../metelitsa-before-children-audit backup/children-before-technical-audit-20261122`.

Принудительная отправка и переписывание истории не нужны. Браузерные проверки сохраняются как инструменты разработки; на опубликованном сайте тестовых зависимостей нет.
